# 3D Animation Website

A responsive, dark premium freelance-learning landing page with an interactive Three.js hero scene.

## Preview locally
Open `index.html` in a modern browser with internet access. The page loads Three.js and Google Fonts from CDNs. For a local server, use any static server (for example, VS Code Live Server).

## Included
- Responsive layout for mobile and desktop
- Interactive 3D geometric hero scene, orbit rings, particles, lighting, and pointer parallax
- Pause/resume motion control and reduced-motion preference support
- Scroll reveal animations and graceful fallback when WebGL/Three.js fails
- Roadmap and skill cards

## Deploy
Publish the `3d-animation-website` folder with any static hosting provider, or copy its contents to the root of a static site. No API keys or backend are required.

Note: This is a front-end website. Forms, payments, login, and analytics are not connected. Income outcomes are not promised.
