# Ethical Video Remix — Claude Skill

A reusable Claude skill for handling social-video recreation requests responsibly while still helping users create strong original content.

## Install
Place `SKILL.md` at:
`.claude/skills/ethical-video-remix/SKILL.md`

Then ask Claude Code:
`Use the ethical-video-remix skill to help me adapt this video into original content without deceptive impersonation.`

## What it does
- Distinguishes original footage from someone else's content.
- Avoids deceptive face/voice replacement and misattribution.
- Offers editing for the user's own footage, fresh scripts, permissioned commentary/remixes, or consent-based avatars.
- Clearly distinguishes an edit plan from an actually rendered/exported video.
- Keeps explanations practical and respectful.

This skill is guidance, not a face-swap tool or video-rendering engine. Actual editing requires accessible footage and compatible editing tools.
