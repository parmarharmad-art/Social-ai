## Verification policy
- A committed file is not the same as a deployed or live integration.
- Never put API keys, OAuth tokens, passwords, or private customer data in this repository.
- Real outbound actions (calls, emails, messages, job applications) must require authorized accounts, applicable consent, and explicit human approval.
- Keep prototype/simulation labels visible until real end-to-end tests pass.
