# NumeroMaster AI
Premium mobile-first numerology web app branded **Kiran Kumar • NumeroMaster AI**.

Includes Pythagorean and Chaldean name calculations, Moolank/Bhagyank, traditional Navagraha associations, Lo Shu grid, mobile-number digit sum, spelling comparison, optional server-side OpenAI reflection, print/PDF, security headers, request cap and basic rate limiting.

Deploy with Node.js 20+, build command `npm test`, start command `npm start`. Set `OPENAI_API_KEY` as a hosting secret for AI reports; never commit the key.

**Commercial blockers:** no customer accounts, live checkout, or subscription entitlement enforcement. Privacy/terms require business details and review. Numerology is not a scientifically validated predictive method.
